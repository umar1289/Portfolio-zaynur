# Bosh sahifa (hero) surati

Shu papkaga **bitta** rasm tashlang — nomi muhim emas, birinchi topilgan
fayl "sex surati — gorizontal" o'rniga avtomatik chiqadi.

Tavsiya etilgan nisbat: 21:8 (masalan 2400×900), gorizontal.

Bu rasm sahifa ochilishi bilan ko'rinadi, shuning uchun (boshqa
rasmlardan farqli) lazy-load qilinmaydi — tezroq yuklanishi uchun
`loading="eager"` va `fetchpriority="high"` bilan beriladi.
